# Validation — 0.2.3 bilingual portable editions

Date: 1 November 2026, Australia/Sydney. Windows 10 build 19045 x64. Existing v0.1.0–v0.2.2 release archives and the currently running working build are preserved.

## Changes

- Separate English and Simplified Chinese Windows x64 portable editions, sharing identical executable binaries.
- Chinese Settings, tray menus, timing menus, numeric status templates, errors, tooltips, positioning choices and overlay edit controls. Diagnostic CLI output and engineering logs remain English.
- Language precedence: explicit `--language`, saved `UiLanguage`, portable `ui-language.txt`, then English. The Chinese launcher passes `--language zh-CN`; its marker also supports first-run direct EXE launch. Restart is required to change the language of an already running shared profile.
- Interface language persists independently of original lyrics, supplemental lyric language tags, timing, colors and display preferences. No lyric content is translated or generated by this localization.
- Packaging excludes user profiles, native/app caches, logs, diagnostics, SDKs and local shortcuts. Both portable editions include the English and Chinese README.

## Automated verification

**254/254 tests passed**, with zero failures or skips. All 247 previous cases remain. Seven new cases check explicit/saved/portable language precedence, unsupported-language fallback, real embedded-catalog loading, Chinese numeric templates, unchanged unknown Unicode text, and language persistence without altering global/per-song correction or native language preferences.

The full suite ran in normal Windows execution because the test sandbox denies named-pipe client connections. The published WPF application and diagnostic built with no warnings or errors. Dependencies were restored from cache using `-Offline`; online vulnerability auditing was unavailable.

## Manual check

1. Extract the chosen language edition into a separate writable folder. Run `Run-Portable.cmd`, confirm the expected Settings language, then close Settings to return to the tray.
2. Check translation and pronunciation independently and together using a previously cached song. Song text and timing must stay the same across interface languages.
3. Adjust global timing, switch songs and restart. Confirm saved global/per-song totals and all appearance preferences remain correct.
4. Lock the overlay and verify physical click-through/focus. Test resolution, DPI and monitor changes on the actual connected hardware.

Private test evidence under `diagnostics/v0.2.3` is excluded from source and release archives.
